### 2. Sin modelo comercial por ahora

No se investigan ni se publican precios, paquetes ni retainers. Queda fuera del alcance de esta etapa.

### 3. Prueba social: hoy no hay ninguna, y es un frente de trabajo

Se investiga cómo construirla desde cero (`TASK-003`).

### 4. Diseño: la única base es la web de assets

No hay patrones de diseño documentados. La única referencia es la web de assets que se hizo: las maquetas estáticas y los bloques del tema `pharmaco`. Se documenta y se contrasta con el benchmark (`TASK-004`).

## Motivo

Es decisión de Miguel. Cambia la investigación: ya no se pregunta **qué** servicios ofrecer, sino **cómo actualizar y presentar** unos servicios ya elegidos.
