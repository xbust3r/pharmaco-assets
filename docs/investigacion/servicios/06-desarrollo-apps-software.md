## 2. Qué incluye hoy el servicio

1. **Diseño de Arquitectura y APIs:** Microservicios, bases de datos escalables y desarrollo en la nube (AWS/GCP).
2. **Aplicaciones Móviles Nativas y Multiplataforma:** Desarrollo para iOS y Android (Flutter, React Native, Swift).
3. **Plataformas Web a Medida y Portales de Clientes:** Dashboards, intranets, motores de cálculo y sistemas transaccionales seguros.

---

## 3. Qué cambió desde 2020

* **En 2020 (Línea base Pharmaco):** Planteado genéricamente como "Desarrollo de software y aplicaciones móviles" sin especialización de stack.
* **En 2026 (Benchmark internacional):** Se denomina **Digital Product Engineering**. Las agencias entregan sistemas desacoplados, aplicaciones asistidas por IA y plataformas integradas con APIs empresariales.
