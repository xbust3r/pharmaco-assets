## Qué cambió desde 2020

No hay base de 2020 para este servicio: la línea base dice «Repite el texto de Social Media» y «Sin redactar».

- **Lo que sigue igual:** no hay base de 2020 para decir qué sigue igual.
- **Lo que se añadió:** en la muestra, la oferta se nombra por medio (paid media, Google Shopping) o por resultado medible (ROI, ROAS). Es lo que aparece en los nombres literales.
- **Lo que desapareció o se volvió básico:** no hay base para afirmarlo.
- **Cambio de nombre o de encuadre:** en 7 agencias de 20 el servicio no aparece con el nombre «Performance». Se nombra por lo que mide (ROI, ROAS) o por el medio (paid media).
