## Qué cambió desde 2020 (servicios 1 a 6)
- **Lo que sigue igual:** Uso de sistemas CMS para que el cliente pueda autoadministrar sus contenidos.
- **Lo que se añadió:** Arquitecturas desacopladas (Headless CMS con Next.js/Nuxt), plataformas No-Code profesionales (Webflow para marketing), cumplimiento estricto de Core Web Vitals de Google, integración de APIs de IA y microservicios.
- **Lo que desapareció o se volvió básico:** Sitios web basados en plantillas comerciales prediseñadas monolíticas y constructores visuales pesados que ralentizan la carga.
- **Cambio de nombre o de encuadre:** El desarrollo web pasó de ser una "página de presentación" a ser la plataforma central de conversión, marca y experiencia digital del negocio.
